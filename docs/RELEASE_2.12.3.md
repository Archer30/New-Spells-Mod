# New Spells 2.12.3 + New Spells Expansion 1.1.0

Download the ZIP assets below for the installable mods. The automatic Source code downloads do not include compiled plugins.

Extract New-Spells-2.12.3.zip into your ERA game's Mods folder. Extract New-Spells-Expansion-1.1.0.zip there as well if you want Reinforcements and Blizzard. Enable the mods in your mod manager; the expansion requires New Spells.

New Spells includes the game plugin, map-editor extension, resources, translations, and debug map. Version 2.12.3 preserves legacy BM:G receiver compatibility outside the reserved New Spells IDs 81–126, including ACM morale/luck aliases and original mastery aliases. Invalid raw memory accesses remain unsafe.

Packages were made from the installed mod folders. The core README additionally retains the requested original-mod credits; all other packaged files match the installed bytes, including the updated author metadata. ZIP entries and integrity were verified. Previous validation covered 63,671 address checks and 9,831 runtime checks; full interactive battle replay and Windows XP VM testing were not completed.
